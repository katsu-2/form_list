# フォーム営業ツール + リスト作成ツール

企業サイトの問い合わせフォーム経由の営業(フォーム営業)を効率化するツール。
設計・ロードマップは [docs/PLAN.md](docs/PLAN.md) を参照。

## 現在の実装状況

**Phase 1: リスト作成 MVP**
- 企業リストの CSV インポート/エクスポート(正規化・重複排除・NGリスト照合つき)
- 問い合わせフォームURLの自動探索(典型パス試行 + トップページのリンク解析、robots.txt 尊重)
- フォーム解析: フィールドの役割推定(会社名/氏名/メール/本文 等)、CAPTCHA検出、営業お断り文言の検出
- 管理画面: 企業一覧(検索・ステータスフィルタ)、フォーム探索実行、NG登録

**Phase 2: フォーム送信 MVP**
- テンプレート管理(`{{company_name}}` 等の変数差し込み)
- 自社情報(差出人)設定 — フォームの会社名・氏名・メール欄等に自動入力
- キャンペーン: ready企業から下書きを一括生成 → 人が確認・承認 → 送信(半自動)
- Playwright 送信エンジン: 入力 → 確認画面遷移 → 完了文言の判定 → 全件スクリーンショット保存
- 安全設計: CAPTCHA検出時は手動対応キューへ(回避しない)、営業お断り文言の送信直前再チェック、
  送信間隔(最低10秒)と日次上限、同一企業への重複送信防止、dry-run(入力のみ・送信なし)モード
- 完了を確認できない場合は「手動確認」扱いにして重複送信を防止

**Phase 3: 自動化・精度向上**
- LLM(Claude API)によるフィールドマッピング補完 — ルールベースで判定できない特殊フォームを補助的に解析。
  `ANTHROPIC_API_KEY` 未設定時は自動でスキップし、ルールベースの結果で動作
- ダッシュボード — 成功率、送信結果の内訳、失敗・スキップ理由の分析、企業ステータス進捗、キャンペーン別サマリ

### LLM補完の有効化(任意)

`ANTHROPIC_API_KEY` を設定するとフォーム探索時にLLM補完が有効になります(未設定でも動作します)。

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export ANTHROPIC_MODEL=claude-opus-4-8   # 任意(デフォルト claude-opus-4-8)
```

## 使い方(送信までの流れ)

1. 「自社情報」で差出人情報を設定
2. 「企業リスト」でCSVをインポートし、各社の「フォーム探索」を実行(status が ready になった企業が送信対象)
3. 「テンプレート」で送信文面を作成
4. 「キャンペーン」を作成すると下書きが生成される → 内容を確認して承認 → dry-run で入力確認 → 送信開始

## セットアップ

```bash
uv sync --extra dev   # または: pip install -e ".[dev]"
```

## 起動

```bash
uv run uvicorn app.main:app --reload
```

http://localhost:8000 で管理画面が開きます。

## テスト

```bash
uv run pytest
```

## CSVインポート形式

ヘッダ行必須。`name` のみ必須、他は任意。

```csv
name,url,corporate_number,industry,address
株式会社サンプル,https://example.co.jp,1234567890123,IT,東京都...
```
